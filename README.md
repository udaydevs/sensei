## ✨ Overview

**Sensei** is a modern AI-powered Japanese learning platform built to make learning Japanese simpler and more intuitive.

Traditional translation tools often give you the meaning of a sentence without explaining **why the sentence is structured that way**.

Sensei takes a different approach — it breaks Japanese sentences down and helps learners understand:

- 🧩 Individual words
- 🔹 Particles
- 📚 Grammar
- 🔤 Pronunciation
- 💬 Context
- 🧠 Sentence structure

The goal is simple:

> **Don't just translate Japanese. Understand it.**

---

## 🚀 Features

### 🧩 Smart Sentence Breakdown

Break Japanese sentences into individual components and understand the role of each word.

- Word-by-word meanings
- Particle identification
- Sentence structure
- Grammar relationships
- Contextual explanations

### 🤖 AI Japanese Tutor

Get explanations from an AI-powered tutor designed to make Japanese concepts easier to understand.

Whether you're confused about a particle, grammar pattern, or sentence structure, Sensei provides an easy-to-follow explanation.

### 🔤 Romaji Support

Not comfortable reading Japanese characters yet?

Sensei provides **Romaji pronunciation** to help beginners read and pronounce Japanese sentences.

**Example:**

```text
おはよう。今日も元気だね。

ohayou. kyou mo genki da ne.
```

### 📚 Grammar Made Simple

Japanese grammar can be difficult when learned through definitions alone.

Sensei focuses on explaining grammar **in context**, making it easier to understand how and when a particular structure is used.

### 💬 Context-Aware Learning

The meaning of Japanese words can change depending on the context.

Sensei helps learners understand:

- Meaning
- Usage
- Grammar
- Context
- Related expressions
- Difficulty level

## ⚡ Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### 1. Clone the repository

```bash
git clone https://github.com/udaydevs/sensei.git
```

### 2. Navigate to the project

```bash
cd sensei
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit:

```text
http://localhost:3000
```
